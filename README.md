# slide-human-workflow

スライド・資料（PPTX/PDF）を、**中身を決める → ラフで確かめる → 設計 → 作る → 論理と数字のチェック → 完成後の全ページ画像チェック**の順で仕上げるAgent Skillです。
見た目の「AIっぽさ」を減らすだけでなく、主張・根拠・判断してほしいことが読み手に通る資料にすることを目的にしています。新しく作るときにも、既存の資料を直すときにも使えます。

## 主な機能

- 持ち時間からの逆算・「話さないこと」の決定・ネストした箇条書きでの取捨選択で、見た目より先に中身を決める
- 構成案と完成スライドの間に「ラフ」の段階をはさみ、色や飾りを付ける前に構成を確かめる
- 資料の種類と目的から、ページごとの主張・強弱・色の役割・文字の大きさを先に決める（設計宣言）
- 情報の関係（時間・手順・因果・比較・推移など）に合う図の型と、グラフの使い分け
- 「やめること → 代わりに判断すること」の対で、カード・色・大きな数字・箇条書きなどの機械的な繰り返しを直す
- 内容（主張・根拠・数字）と、画像で見る見た目の両方をチェックリストで確かめる
- スライドを全ページ画像にして一覧で見るスクリプト付き
- 作った・直したファイル・ページごとのレビュー表・要確認の一覧を渡す

## ファイル構成

- `SKILL.md` — 進め方とルール
- `references/content-first.md` — 中身を決める手順（量の逆算、話さないこと、ネストした箇条書き、取捨選択、スライドの文章の原則）
- `references/layout-patterns.md` — 図の型、グラフの使い分け、メッセージライン、見た目の基本ルール
- `references/preflight-and-replacements.md` — 作る前の設計宣言、「やめること → 代わりにすること」、資料の種類による例外
- `references/checklist.md` — 内容と構成（A）、画像で見る項目（B）、仕上げ（C）、レビュー表
- `references/render.md` — 画像にして確かめる方法
- `scripts/render_pages.py` — PPTX/PDF をページ画像と一覧画像にするスクリプト

## 導入

Agent Skillsに対応する実行環境のスキルディレクトリに、このフォルダを `slide-human-workflow` として配置してください。対応する実行環境で `SKILL.md` を読み込み、記載の手順に従います。

画像チェックに使うもの：

- Python 3 と Pillow（`pip install pillow`）
- LibreOffice（PPTX を PDF にするとき）
- pdftoppm（Poppler）

## 使い方の例

- 「この内容でスライドを作って。AIっぽくしないで」
- 「スライドを作る前に、中身と構成を一緒に決めたい」
- 「このPPTXのAIっぽさを消して」
- 「このスライドをレビューして、直して」

## 注意

- 元資料の事実・数字・固有名詞は変えません。根拠が分からないものは「要確認」として残します。
- 元のファイルは上書きせず、コピーを直します。
- 何を伝えて何を削るかは、利用者が判断できる形（残す・削るの一覧、おすすめ1つ）で確認します。
