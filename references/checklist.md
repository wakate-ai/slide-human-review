# チェックリスト

絶対の禁止事項ではない。どの項目も、**情報の上で理由があれば「理由があって残す」**にしてよい。
各項目は「問題あり／理由があって残す／あてはまらない」のどれかで記録する。

## A. 内容と構成（画像を見る前に確かめる）

- [ ] A1. 各スライドの主張を1文で言える。「導入ステップ」「今後の展望」のような、中身のないタイトルになっていない。
- [ ] A2. 誰に何を理解・判断してほしいのか分かる。決裁資料なら、決める対象と根拠が対応している。
- [ ] A3. 1枚に、概要・リスク・判断事項・スケジュールを機械的に全部詰め込んでいない。
- [ ] A4. 「伴走」「可能性を引き出す」「高度化」のような言葉に、具体的な業務や担当が対応している。
- [ ] A5. 「ご判断いただきたい点」のような同じ箱を、全ステップに機械的に置いていない。
- [ ] A6. 見出しと補足で、同じことを言い換えて繰り返していない。
- [ ] A7. 数字の根拠・時点・母数・単位・計算方法を確かめた。未確認の情報を実績のように書いていない。
- [ ] A8. 持ち時間（またはページ数の目安）に合った量になっている。話さないこと・載せないことが決まっている。
- [ ] A9. 調べた経緯、却下した案、元データを見れば分かる一覧を、判断に関係なく並べていない。
- [ ] A10. どの項目も同じ重さで並んでいない。いちばん伝えたいことと補足の差が、構成から分かる。
- [ ] A11. 判断してほしい点に、選択肢とおすすめ1つが付いている（あてはまるとき）。

## B. 画像で見る項目（全ページの一覧画像と、各ページの画像で確かめる）

- [ ] B01. **意味のない飾り線・帯・仕切り**：線が構造の区切りとして働いているか。ただのアクセントなら削れないか。
- [ ] B02. **同じ大きさのカードの繰り返し**：主役と補足が同じ幅・大きさのせいで埋もれていないか。（比べるための同じ形は残してよい）
- [ ] B03. **数字・見出しの強さが全部同じ**：結論の数字1つと、それ以外に強弱があるか。
- [ ] B04. **理由のない背景色の切り替え**：ページごと・交互に背景を変えていないか。変える理由を説明できるか。
- [ ] B05. **色の意味がばらばら**：強調・警告・効果などの色の意味が、資料全体で同じか。
- [ ] B06. **強調色が広がりすぎ**：見出し・線・数字・全部の棒・アイコンを、同じ強調色にしていないか。強調したいのが1本なら、残りは落ち着いた色にできないか。（カテゴリごとの色分けに意味があれば残す）
- [ ] B07. **アイコンが言葉の代わり**：それっぽいアイコンが、内容の説明の代わりになっていないか。
- [ ] B08. **飾りの写真・模様・透かし**：説明の邪魔になっていないか。
- [ ] B09. **見出し・補足・数字の重複**：1文で言えることを、何行にも分けて繰り返していないか。
- [ ] B10. **タイトルと図表が別の話**：タイトルの結論（「合計20時間」など）が、図表で確かめられるか。
- [ ] B11. **一覧表のまま**：全部の列が判断に必要か。担当別・工程別に分けたほうが見やすくないか。
- [ ] B12. **詰め込みすぎ**：余白を埋めすぎて、文字が小さい・ぎゅうぎゅうになっていないか。
- [ ] B13. **全ページが同じ強さ**：毎ページ大きな数字・カード・強い見出しが続いていないか。主役のページと補足のページがあるか。
- [ ] B14. **語尾・用語の不揃い**：同じ階層のラベルで、名詞止め・動詞止めや用語がそろっているか。
- [ ] B15. **1枚の役割が混ざっている**：1枚に役割が複数ないか。根拠が別のページに飛んでいないか。
- [ ] B16. **文字の大きさに差がない**：キーメッセージとそれ以外の大きさに、はっきり差があるか。
- [ ] B17. **文字が小さすぎる**：本文が18pt目安（大きな会場で投影するなら24pt目安）を下回っていないか。注記も読める大きさか。
- [ ] B18. **コントラストが低い**：文字と背景の差が小さく、投影すると読めなくならないか。
- [ ] B19. **揃えがばらばら・中央揃えだらけ**：左端がそろっているか。中央揃えに理由があるか。
- [ ] B20. **文章が長い**：1枚に5行以上の文章、深い階層の箇条書きが残っていないか。
- [ ] B21. **よく見る型のまま**：グラデーション・絵文字・アイコン付きカードの並び・「Key Message」のような枠など、資料の中身と関係なく入った定番の要素がないか。

## C. 仕上げ（直したあと、もう一度画像にして確かめる）

- [ ] 全ページの一覧で、同じ構図・色・カードが続くところがない（理由があるものは除く）。
- [ ] 表紙・目次・章構成・目次に書いたページ番号・実際のページ番号・出典・フッターが合っている。
- [ ] 文字切れ・重なり・はみ出し・余白不足・小さすぎる注記・色の見えにくさがない。
- [ ] 固有名詞・数字・表・グラフが元資料と一致し、意図しない変更がない。
- [ ] 読み手が何を理解・判断するかを、ひとことで説明できる。

## 優先度の付け方

- **必須**：事実の誤り、数字の矛盾、タイトルと図表の不一致、伝えるべき結論が分からない。
- **推奨**：強調どうしがぶつかる、色の意味が合わない、同じ構図の繰り返しが多すぎる、いらないカードや枠。
- **残す**：比べるための同じ幅のカード、カテゴリに対応した複数の色、一覧が必要な表など、目的を説明できるもの。
