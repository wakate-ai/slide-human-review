# よく使う図の型とグラフの使い分け

毎回ゼロからレイアウトを考えず、情報の関係に合う型を選ぶ。型は出発点で、情報に合わせて大きさや強弱を調整する。
同じ型を全ページに当てはめない。比べるために同じ形を繰り返すときだけ、繰り返しを残す。

## 1. 情報の関係 → 型

| 情報の関係 | 合う型 | 使うときの注意 |
|---|---|---|
| 時間（いつ何をするか） | 時系列・フェーズ図（期間ごとの帯を上から下、または左から右に並べる） | 期間のラベルと、そのフェーズで何をするかを1行で添える。今どこにいるかを示すなら、そこだけ強調する |
| 手順（順番に進む） | フロー図（矢印でつなぐ） | 分かれ道があれば分岐を描く。手順が多すぎるなら段階でまとめる |
| 因果（何が原因で何が起きるか） | 原因 → 結果の図、ツリー | 原因と結果の大きさをそろえない。言いたい側を主役にする |
| 比較（AとBの違い） | 左右に並べる、比較表、比較棒グラフ | 比べる軸をそろえる。比べるための同じ形は残してよい |
| 並列（同じ重さのものが複数） | 同じ形を並べる | 本当に同じ重さかを確かめる。主従があるなら大きさや位置で差を付ける |
| 主従（中心と補足） | 中心を大きく、補足を小さく | 全部を同じ幅のカードにしない |
| 推移（数字の変化） | 折れ線グラフ | 見てほしい変化（伸び・鈍化・転換点）に注釈を付ける |
| 構成比（全体の内訳） | 積み上げ棒、帯グラフ | 項目が多すぎるなら「その他」にまとめる |

## 2. グラフの使い分け

- **推移**は折れ線、**量の比較**は棒、**2つの条件の比較**は比較棒（並べた棒）や2本の折れ線にする。
- 例：「何もしない場合」と「投資した場合」の利益計画を2本の折れ線で比べると、一時的な伸びの鈍化の理由と、その先の伸びを同時に説明できる。
- グラフのタイトルにも結論を書く（「売上推移」ではなく「〇年以降、売上の伸びが戻る」）。
- 強調したいのが1本なら、その1本だけ強調色にし、残りは落ち着いた色にする。
- グラフを生成AIに描かせるときは、元データと、参考にしたい図の見本を一緒に渡す。数字はAIに作らせない。

## 3. メッセージラインを置く

- 各ページの決まった位置（タイトルの下、または左側の帯など）に、そのページの主張を1行で書く場所を固定する。
- 読み手は、メッセージラインだけを追えば話の流れが分かる。
- 図やグラフはメッセージラインの根拠として置き、メッセージと図の内容を一致させる。

## 4. 見た目の基本ルール

- **文字の大きさ**：本文は18pt以上を目安にする。大きな会場で投影するなら24pt以上を目安にする。
- **文字の大きさの差（ジャンプ率）**：キーメッセージ以外はわざと小さくし、「全部読まなくてよい」と分かるようにする。
- **色**：ベースカラーとアクセントカラーの2色が基本。3色以上使うなら、色ごとの意味を決める。
- **揃え**：中央揃えは使いどころが難しいので、基本は左端をそろえる。見えない枠線を意識して配置する。
- **コントラスト**：投影する資料は、文字と背景の差をはっきり付ける（目安としてコントラスト比 9:1）。プロジェクターでは画面より薄く見える。
- **余白**：空いたところを無理に埋めない。
- **アニメーション**：入れるなら話の流れに合わせて意図を持って使う。中途半端なアニメーションはかえってノイズになる。
